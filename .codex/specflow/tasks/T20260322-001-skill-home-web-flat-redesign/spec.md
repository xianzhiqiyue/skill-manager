# 任务规格（spec）

## 1. 任务信息
- 任务ID：T20260322-001
- 任务标题：Skill-Home Web Flat Redesign
- 负责人：Codex
- 创建日期：2026-03-22

## 2. 背景与目标
### 2.1 背景
- 业务背景：Skill-Home 已具备 Registry、CLI、Web 三条链路，Web 需要从“宣传页 + 轻控制台”升级成真正的技能发现与安装入口。
- 技术背景：当前前端主要聚合在单页组件内，宣传、搜索、发布、登录、管理等流程混排，不利于信息架构与后续扩展。

### 2.2 目标
- 目标1：将 Web 重构为扁平风、多页面结构，形成官网、技能中心、详情页、发布页、控制台的清晰分层。
- 目标2：把技能中心和 AI 安装指引做成主路径能力，显著提升发现、理解、安装效率。

## 3. 范围与非目标
### 3.1 本次范围（In Scope）
- 重构前端信息架构与页面分层。
- 新增全站顶部导航栏。
- 新增技能中心页面并增强查找能力。
- 优化技能详情与 AI 安装指引。
- 将发布页和控制台从首页拆出。
- 统一视觉风格为扁平风并提高信息密度。
- 沉淀公开规格文档到 `docs/skill-home-web-redesign-spec.md`。

### 3.2 非目标（Out of Scope）
- 不改动后端鉴权模型。
- 不做数据库 Schema 变更。
- 不在本阶段引入无关组件库迁移。
- 不在本阶段扩展服务端为全量高级搜索引擎，只记录接口增强建议。

## 4. 约束与禁改项
- 禁止无关重构：是
- 禁止依赖升级：是
- 禁止数据库 Schema 变更：是
- 其他约束：先完成文档，再按 step 逐步落地；每步仅修改必要前端文件。

## 5. 影响面分析
- 前端模块：`skill-home-web/src/App.tsx`、`skill-home-web/src/api.ts`、`skill-home-web/src/styles.css`，后续将拆分为路由、页面和组件。
- 后端模块：当前仅可能涉及搜索参数与详情展示字段，先不动实现。
- 接口契约：短期沿用现有 API；中期建议增强 `/api/v1/search` 和 `/api/v1/skills`。
- 配置与部署：前端构建产物仍部署到 `/opt/skill-home/web`，不改变现有接入方式。

## 6. 验收标准（Definition of Done）
- [ ] 前端从单页改为多页面路由结构。
- [ ] 顶部导航全站可用，桌面与移动端均可访问。
- [ ] 技能中心具备增强后的搜索、筛选和高密度浏览能力。
- [ ] 技能详情具备 AI 安装指引和一键复制能力。
- [ ] 发布页与控制台从首页剥离。
- [ ] `npm run build` 通过，完成基础 smoke test。

## 7. 风险与缓解
- 风险：现有搜索接口能力有限，前端难以完全实现理想中的技能中心。
- 缓解：先完成结构重构与已有能力增强，将接口增强项记录在文档与计划中，必要时作为后续 step 单独推进。

## 8. 里程碑
- M1：完成规格文档、执行计划和任务基线。
- M2：完成路由骨架、导航、首页与技能中心。
- M3：完成详情页、AI 安装指引、发布页、控制台和回归。
